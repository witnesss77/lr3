ЛАБОРАТОРНАЯ РАБОТА. ОСНОВЫ PHP

Цель:
Научиться заменять отдельные статические фрагменты HTML-кода на PHP-код.

Файлы:
original.html — исходная статическая страница.
index.php — та же страница, но с динамическим выводом HTML через PHP.
style.css — простое оформление (одно для обеих страниц).

Что сделано:
1. Созданы переменные $title и $student, их значения выводятся через echo.
2. Создан массив $topics с тремя названиями тем.
3. Цикл foreach формирует строки HTML-таблицы.
4. Функция count() выводит количество элементов массива.
5. Условие if/else определяет текст о ходе изучения тем.

Как запустить в XAMPP на Windows:
1. Запустить XAMPP Control Panel.
2. Нажать Start рядом с Apache.
3. Скопировать папку php_laboratory_simple в C:\xampp\htdocs\.
4. Открыть в браузере http://localhost/php_laboratory_simple/index.php
5. Для сравнения открыть http://localhost/php_laboratory_simple/original.html

Как выложить на сервер через FTP (если преподаватель дал доступ):
1. Открыть FileZilla (или другой FTP-клиент).
2. Ввести адрес сервера, логин и пароль, полученные от преподавателя.
3. Загрузить index.php и style.css в указанную папку сайта.
4. Открыть адрес сайта в браузере. PHP на сервере должен быть включён.

Что сказать на защите:
"Я сделал обычную HTML-страницу и заменил некоторые фрагменты PHP-кодом.
С помощью echo выводятся текст и заголовок, цикл foreach создаёт строки таблицы,
count считает количество тем, а if/else выводит сообщение по условию.
Результат PHP — обычный HTML, который показывает браузер."
